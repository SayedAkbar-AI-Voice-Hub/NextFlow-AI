# Marketing Hub Agency

AI-Powered Marketing & Branding Agency website. We help businesses build their brand, dominate social media, and generate leads using cutting-edge AI marketing strategies.

## Features

- **AI-Powered Marketing** - Automated content creation, scheduling, and optimization
- **Social Media Management** - Full platform coverage (Instagram, Facebook, LinkedIn, Twitter, TikTok)
- **Branding & Design** - Logo design, brand guidelines, visual assets
- **Lead Generation** - Automated funnels and landing pages with opt-in forms
- **SEO & Content** - AI-powered content strategy and optimization
- **Paid Advertising** - Data-driven Google Ads and social media campaigns
- **Email Marketing** - Automated sequences with AI-written copy

## Tech Stack

- **React 19** - Latest React with improved performance
- **TypeScript** - Full type safety
- **Vite** - Lightning-fast build tool and dev server
- **TailwindCSS** - Utility-first CSS framework
- **Lucide React** - Beautiful icons
- **Cal.com** - Embedded booking calendar

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

1. Navigate to the project directory:
```bash
cd "Marketing Hub agency"
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open [http://localhost:3002](http://localhost:3002) in your browser.
